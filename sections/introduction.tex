\section{Introduction}
\subsection{Identifying \LaTeX's key accessibility problems for screen reader users}
Similar to a tool like Microsoft Word, \latexspaced is a tool used to process documents. \latexspaced does this in a programmatical manner, likening it to a programming language, whereas Microsoft Word has a \acrfull{gui} which simplifies the process for an ordinary user. However, \latexspaced prevails in its ability to process scientific documents which may require graphs, images, tables, or advanced mathematical capabilities.

\latexspaced struggles to implement accessibility for screen readers, largely due to it not originally being built for that purpose, as explained in \cref{intro:lualatex_better_pdflatex}. Additionally, \latexspaced is broken by design, originally created as a set of macros built on the \texspaced typesetting engine that has evolved to the \lualatexspaced that we can work with in modern times.

Additionally, \acrfull{pdf} files are built to not be changed, which adds difficulties in attempting to add \gls{tagging}.
\subsection{Why accessibility is important}
Accessibility has the potential to assist all users, even if it is aimed a few focus groups, with one such case being where an environment, such as a noisy train, restricts the user from hearing the audio output of a video. In this context, an accessibility feature such as subtitles on a video, ideally without \acrfull{ai} generation, can greatly enhance a user's experience.

For example, in Northern Ireland alone, there are an estimated 8,000 users with sight loss \parencite{accessibility_importance}. These users may require the assistance of screen readers or someone else to read it out to them, which can add to their stresses, with the context simply not being built with their needs in mind.

Users with disabilities are over 50\% more likely to face difficulties due to a lack of digital inclusion \parencite{accessibility_importance}, which highlights the severity of its impact on a website's overall traffic. These users should not be an afterthought of the website's design, but rather a key focus.

\subsection{Why LuaLaTeX provides better accessibility than PDFLaTeX}\label{intro:lualatex_better_pdflatex}
\pdflatexspaced was created to be a media printer, such that it produced PDF documents with the sole purpose of being printed out. Due to its innate design, this means it lacked support for screen reader users. \pdflatexspaced also frequently has outdated, or frankly broken, workarounds to implement accessibility, such as the accessibility package \parencite{accessibility_package} which has been deprecated since February 2021. Additionally, as its focus has shifted to maintenance rather than development, \pdflatexspaced is unsuitable for accessibility where requirements change frequently, making it an outdated \texspaced engine, which unfortunately still sees frequent usage.

The introduction of \xetexspaced improved font handling in \latex , yet its lifetime was short-lived, with it almost being considered an evolutionary deadend, at the addition of \lualatex.

Unlike \pdflatex, \lualatexspaced was created for the purpose of creating electronic documents, giving its development a suitable reason to support screen reader users through use of \gls{alt_text} and \gls{tagging}. Our tool, \lintex, utilises \lualatex's accessibility support, with emphasis placed on screen reader users.
\subsection{Aims and objectives}
This project aimed to enhance \latexspaced documents' accessibility, with a focus placed on screen reader users, by creating a prototype, \lintex , which analyses a \latexspaced document to identify where to apply \gls{alt_text} and \gls{tagging}.

The following objectives were created for this context:
\begin{enumerate}[label=\textbf{OBJ\arabic*}]
    \item The tool, \lintex , should be maintainable, as accessibility often requires changes to its handling.
    \item \lintexspaced should improve a document's audio output in terms of its contents, when read by a screen reader.
    \item \lintexspaced should provide useful error messages and descriptive.
    \item \lintexspaced should be reasonably accessible, following the accessibility guidelines defined in \cref{backg:accessibility_guidelines}.
\end{enumerate}
